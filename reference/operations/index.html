    select_upstream_subbasins(
    *,
    fabric: HydroFabric,
    target: Targets,

    n_jobs: int = 1,
) -> BatchResult[list[Subbasin]]

    Select whole sub-basins approximating land draining to a target.

    Parameters:

    Name Type Description Default
    fabric HydroFabric

    Open HFX fabric supplying catchments and upstream connectivity.

    		 required
    target BaseGeometry | Targets

    EPSG:4326 geometry, or a dictionary of named geometries or list for a batch. A multipart geometry is one target. Regions include boundary intersections. A point on a shared boundary belongs to the smallest supplied catchment ID; river associations do not determine ownership.

    		 required
    level int

    Nonnegative catchment level, selected explicitly without fallback.

    		 1
    n_jobs int

    Batch worker limit: 1 is sequential, -1 uses available CPU capacity, and positive values bound worker-owned readers. Single calls are serial.

    		 1

    Returns:

    Type Description
    list or BatchResult

    Whole intersecting units and their inclusive upstream closure. An empty geometry succeeds with an empty list. Batch slots preserve input order; dictionary keys are names, while list entries get new UUID names on each call. Duplicate geometries remain independent targets.

    Raises:

    Type Description
    OperationError

    selection.invalid_target for invalid geometry, selection.no_coverage for a nonempty target without coverage, or selection.connectivity_unavailable for unsupplied connectivity. Batches retain these failures as issues with None result slots.
    ValueError

    Invalid level or worker count, or a flow relationship crossing levels.
    TypeError

    Invalid target type or batch names.
    Notes

    This is whole-unit selection, not exact-point raster delineation. Returned vectors survive fabric closure. Integrity, configuration and unexpected failures propagate even in batches; they are not empty selections.

    Compose snapping, upstream selection, optional refinement and merging.

    Parameters:

    Name Type Description Default
    fabric HydroFabric

    Open fabric used for all source access.

    		 required
    target BaseGeometry | Targets

    EPSG:4326 geometry, named dictionary or list of geometries. Batch naming and whole-unit selection follow select_upstream_subbasins.

    		 required
    level int

    Explicit catchment level; no fallback or automatic finest-level choice.

    		 1
    snap_onto SnapGeometry | None

    Optional supplied stream geometry accepted by snap. Snapping occurs before selection and requires a point; it is never inferred.

    		 None
    radius float

    Maximum snap distance in WGS84 ground metres, finite and nonnegative. Validated even when snapping is disabled.

    		 100.0
    refine bool

    Request raster refinement of the adjusted point under the equivalence assumption described by pourpoint.refinement.refine. Failure does not fall back to a coarse result.

    		 False
    merge bool

    Populate the merged geometry as well as retaining individual sub-basins.

    		 True
    window_size int

    Positive odd native-cell outlet search width. Validated even without refinement. This is a practical choice, not a universal scientific optimum.

    		 3
    n_jobs int

    Batch worker limit: 1 is sequential, -1 uses available CPU capacity, and positive values bound worker-owned readers.

    		 1

    Returns:

    Type Description
    DelineationResult or BatchResult

    Whole units or refined contributions, optional merged geometry, original and adjusted targets, source declarations, and any selected outlet and raster subsets. Batch identity and order are retained.

    Raises:

    Type Description
    OperationError

    Single-target failures use the codes of snap, select_upstream_subbasins and pourpoint.refinement.refine. Batches record them as issues and None slots, not coarse successes.
    ValueError

    Invalid level, worker count, radius or window size, or invalid supplied stream geometry. Shared configuration and integrity failures propagate rather than becoming batch issues.
    TypeError

    Invalid target types or nonboolean refinement/merge controls.
    Notes

    No separate delineation algorithm is used. Vector outputs are materialized and remain usable after fabric closure. Vector snapping and raster outlet adjustment are distinct: the latter is retained in outlet_cell.

    Trace incoming native D8 flow inside a complete vector mask.

    Parameters:

    Name Type Description Default
    fabric HydroFabric

    Open fabric supplying the native direction/accumulation pair.

    		 required
    target Point | None

    Nonempty point in EPSG:4326 covered by the mask. Omit for a selection batch, which carries its own target geometries.

    		 None
    subbasins Sequence[Subbasin] | BatchResult[list[Subbasin]] | None

    Whole source units forming one mask, or a selection BatchResult. Mutually exclusive with footprint. Batch identity, order and prior issues are preserved; failed slots are not retried.

    		 None
    footprint BaseGeometry | None

    Nonempty Polygon or MultiPolygon in EPSG:4326, used as one mask. Supply exactly one mask form. Batch footprints come from subbasins.

    		 None
    window_size int

    Positive odd search width in native cells around the cell containing the target. Size 1 permits no move beyond that cell. Selects the highest valid accumulation inside the mask, breaking ties by source row then column. Both bands must be valid for outlet selection.

    		 3
    n_jobs int

    Batch worker limit: 1 is sequential, -1 uses available CPU capacity, and positive values bound worker-owned readers.

    		 1

    Returns:

    Type Description
    GranularRefinement or FootprintRefinement or BatchResult

    Contributions for sub-basin input or one footprint for geometry input, plus the selected native outlet cell and materialized raster subsets. Empty source pieces are omitted. Both forms trace the same combined mask; merging granular contributions yields the footprint result.

    Raises:

    Type Description
    OperationError

    refinement.point_required for a nonpoint or empty point geometry, refinement.empty_mask for an empty or nonpolygon mask, refinement.outside_mask when the point is not covered, refinement.missing_rasters for an absent raster pair, refinement.no_coverage for inadequate raster coverage, or refinement.no_outlet when the local search has no valid masked cell. Batches retain these failures as issues with None slots.
    ValueError

    Invalid window/worker count or mutually incompatible mask arguments. Integrity and unexpected errors also propagate, including in batches.
    TypeError

    A single call omits target.
    Notes

    Assumes the whole vector mask equals the raster watershed at the terminal unit outlet, and that the requested point drains to that outlet. Execution does not verify this scientific equivalence. The default local search is a practical choice, not a universal optimum; larger windows can switch branches.

    Mask cells use GDAL center-based rasterization. Reverse D8 tracing spans the entire mask and needs only valid direction, not valid accumulation; zero and signed negative directions are terminal. Paths cannot leave the mask. Native direction pointers are never warped. Selected cell polygons are transformed to EPSG:4326 and clipped to the vector mask, then partitioned at source boundaries for granular output. No hole filling is applied. Materialized vectors survive fabric closure; perform source-dependent operations and export within the fabric context.

    pourpoint.snap(*, target: BaseGeometry, onto: SnapGeometry, radius: float) -> Point

    Find the nearest point on supplied streams within a search radius.

    Parameters:

    Name Type Description Default
    target BaseGeometry

    Nonempty finite Point in EPSG:4326 (longitude, latitude).

    		 required
    onto SnapGeometry

    LineString, MultiLineString, River, RiverNetwork or sequence of rivers. Stream vertices must be finite and in EPSG:4326.

    		 required
    radius float

    Maximum WGS84 ground distance in metres, finite and nonnegative.

    		 required

    Returns:

    Type Description
    Point

    Snapped location in EPSG:4326. Equal-distance matches retain input order.

    Raises:

    Type Description
    OperationError

    snap.point_required for an invalid WGS84 point; snap.no_match when no supplied stream is in range.
    ValueError

    Invalid radius or stream geometry. Split segments spanning 180 degrees or more of longitude before calling.
    Notes

    Intended for local stream segments, not arbitrary globe-spanning lines. Segments interpolate straight in longitude/latitude, not along great-circle arcs; distances are measured on the WGS84 ellipsoid. This optional operation neither infers a network nor selects a raster outlet cell.

    pourpoint.select_rivers(*, fabric: HydroFabric, target: BaseGeometry | Subbasin | SubbasinContribution | Sequence[Subbasin | SubbasinContribution], level: int = 1, include_downstream: bool = False) -> RiverNetwork

    Select river portions inside one combined footprint.

    Parameters:

    Name Type Description Default
    fabric HydroFabric

    Open fabric supplying rivers and their relationships.

    		 required
    target BaseGeometry | Subbasin | SubbasinContribution | Sequence[Subbasin | SubbasinContribution]

    EPSG:4326 polygonal geometry, sub-basin/contribution, or collection of parts forming one footprint. Internal part boundaries do not limit flow; this collection is not a batch of independent targets.

    		 required
    level int

    Nonnegative river level, independent of catchment levels. No fallback or inferred correspondence between catchment and river tiers is used.

    		 1
    include_downstream bool

    Extend along every supplied outgoing continuation, including splits and reconvergence. Features are deduplicated by source ID. Partial boundary features require unambiguous orientation to retain downstream linework.

    		 False

    Returns:

    Type Description
    RiverNetwork

    Selected portions with original identities, attributes, directed relationships and supplied nodes. Source quantities are not recomputed. Empty footprints or no intersecting rivers give an empty network when the river family and its relationship data are supplied. Materialized results survive closure.

    Raises:

    Type Description
    OperationError

    rivers.unavailable when the river family is absent; rivers.connectivity_unavailable when extension needs a missing downstream_ids column in supplied relationship data; rivers.ambiguous_direction when a partial feature cannot be oriented from supplied orientation or endpoint nodes.
    KeyError

    River relationship data are not declared, even for an empty footprint or no matching rivers. Missing referenced source IDs also raise.
    ValueError

    Invalid level, nonpolygonal nonempty footprint, or downstream flow crossing river levels. Integrity errors propagate rather than producing a partial network.
    Notes

    Clipping creates endpoints, not natural outlets. Retained relationship references outside the selection must not be interpreted as missing flow or source-described termination. No mainstem is inferred from node incidence.

    pourpoint.QGISBundle

    Build a portable QGIS folder incrementally without hydrological computation.

    Notes

    Add methods retain data and return this builder for chaining. write creates a new folder with a relative-reference project, GeoPackage and native-grid GeoTIFFs; it never replaces an existing path. No merging, delineation or river tracing is performed implicitly. Perform source-dependent export inside the fabric context; current raster subsets already contain materialized arrays.

    Scalar source fields become ordinary vector columns. Reserved-name collisions gain source_ prefixes; source_metadata.attribute_columns records names. Rich values, original WKB and Arrow schemas/metadata are losslessly retained as IPC streams in source_arrow. Result locations are WGS84 WKB in result_metadata, alongside provenance; these are not extra map layers.

    add_result(result: ExportResult | BatchResult[ExportResult]) -> Self

    Add available delineation or refinement outputs without computing more.

    Parameters:

    Name Type Description Default
    result ExportResult | BatchResult[ExportResult]

    A single result or its batch container. Each batch target gets its named group and retained identity; failures go into target_issues without fabricated features. Available outputs include sub-basins, merged footprint, outlined native-CRS outlet cell and one raster pair per refined target. Overlapping targets may duplicate pixels. Granular refinement is not silently merged into another layer.

    		 required
    Notes

    Original and vector-adjusted targets and provenance are retained in result_metadata when available, not added as extra map layers.

    write(path: str | Path) -> Path

    Write the accumulated layers to a new portable folder.

    Parameters:

    Name Type Description Default
    path str | Path

    New output directory. Missing parents are created.

    		 required

    Returns:

    Type Description
    Path

    Output folder containing watershed.qgz, vectors.gpkg and any raster_*.tif files. Project references are relative so the entire folder can be moved together.

    Raises:

    Type Description
    FileExistsError

    The destination already exists; it is never overwritten.
    ValueError

    A raster subset lacks retained source values or source nodata.
    Notes

    Serializes retained arrays and vector records, with no hidden hydrological operations. Cost scales with exported features and pixels, including duplicated pixels across targets. Writes are not transactional across the folder: a failure may leave partial files for the caller to remove.
