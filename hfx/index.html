    HFX

    HydroFabric Exchange (HFX) is a format for sharing hydrofabric data.

    In HFX, we understand a hydrofabric as a dataset that tiles the landscape into sub-basins, describes their downstream connections and provides the river network alongside auxiliary data, when available, such as the flow-direction and flow-accumulation rasters used to produce it.

    The map below shows the GRIT hydrofabric over Switzerland. Each grey polygon is a sub-basin, with the supplied rivers shown in blue. The dataset is clipped to Switzerland for display.

    Boundaries: Natural Earth. Their depiction implies no position on territorial status.

    HFX brings these pieces together in a bundle with a common structure. It preserves source identities, attributes, connections and provenance, and describes where each part of the dataset can be found. This lets tools such as Pourpoint read prepared hydrofabrics through one interface to select rivers and delineate watersheds.

    The documentation explains the data model, bundle organization, vector storage and optional native-grid rasters. This repository contains the specification and supporting tools for preparing and verifying bundles.
